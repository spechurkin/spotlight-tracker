# 🇬🇧 Spotlight Tracker | 🇷🇺 Трекер спотлайта

[English](README.en.md) | **Русский**

Самостоятельный системонезависимый модуль для Foundry VTT 12, который считает,
сколько игрового времени получает каждый персонаж за сессию.

## Возможности

- выбор персонажей, назначенных пользователям-игрокам, без привязки к конкретной игровой системе;
- передача спотлайта кликом по портрету или кнопкой «Следующий»;
- настраиваемый обратный таймер спотлайта от 1 секунды до 180 минут;
- точный подсчёт реально использованного времени по серверным меткам Foundry;
- пауза, продолжение, перезапуск таймера и уведомление об истечении времени;
- доля общего времени и количество передач спотлайта для каждого персонажа;
- сохранение состояния мира при закрытии окна и синхронизация между клиентами;
- режим просмотра для игроков, который мастер может отключить;
- изменение порядка персонажей прямо в основном окне;
- архив последних 20 сессий и публикация таблицы текущей сессии в чат;
- русская и английская локализации.

## Использование

1. Нажмите отдельный значок персонажа в лучах в левом списке инструментов сцены,
  либо откройте трекер из настроек модуля.
2. Назначьте каждому пользователю-игроку персонажа в Foundry, затем нажмите
  «Состав» и выберите нужных персонажей. NPC и актёры, доступные игрокам только
  по правам владельца, в этот список не попадают.
3. Задайте длительность слота в минутах и секундах и нажмите «Применить».
4. Кликните по портрету первого персонажа. Начнётся обратный отсчёт.
5. Передавайте фокус следующему персонажу кликом или кнопкой «Следующий» — для
  него таймер начнётся с полной заданной длительности.
6. Нажмите «В чат», чтобы опубликовать текущую статистику в виде таблицы.
7. В конце игры нажмите «Завершить сессию», чтобы сохранить результат в истории.

Удаление персонажа из состава не стирает уже записанное за текущую сессию
время: строка останется в статистике с пометкой «вне состава». Если удалить
активного персонажа, таймер безопасно встанет на паузу.

## Макросы и API

После загрузки мира доступен API модуля:

```js
game.modules.get("spotlight-tracker").api.open();
game.modules.get("spotlight-tracker").api.focus(actorId);
game.modules.get("spotlight-tracker").api.next();
game.modules.get("spotlight-tracker").api.pause();
game.modules.get("spotlight-tracker").api.start();
game.modules.get("spotlight-tracker").api.setTimer(300); // пять минут
game.modules.get("spotlight-tracker").api.resetTimer();
```

Все изменяющие состояние методы выполняются только от имени мастера.
